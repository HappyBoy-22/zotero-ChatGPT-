# 使用指南

## 设置入口

所有选项位于 **编辑 → 设置 → ChatGPT 论文助手**：

- **PDF 批注默认样式**：设置文字、画笔和橡皮擦；单独点击“保存批注样式”，无需填写账号。
- **论文分析**：修改 prompt，选择是否在首次展开论文聊天时自动发送。
- **登录**：可选保存邮箱密码、尝试自动登录，或删除已保存的凭据。

## 每篇论文一个对话

1. 先确认 Zotero 父条目中的标题、作者和 DOI 等基本信息正确。
2. 打开 PDF，点击右上角“ChatGPT”。新窗口的侧栏初始关闭，展开后切换论文会保持展开。
3. 在嵌入页面登录 ChatGPT。系统浏览器已经登录，并不代表此处已经登录。
4. 默认自动发送开启时，插件会发送自定义 prompt 和基本信息。首条消息生成对话地址后，插件尝试自动保存到对应论文。
5. 切换到其他论文，再返回原论文，会恢复对应的旧对话。

同一父论文下的不同附件使用同一绑定；不同论文使用独立对话。绑定以本机的文库与条目标识保存，不会跟随 Zotero 同步，也不会自动导入浏览器中的所有历史对话。

侧栏“开始分析”可触发初始化流程。已绑定并初始化的论文不会因此重复发送初始资料。关闭自动发送后，可以在准备好时使用该入口。

### 恢复已有对话

在侧栏展开“对话管理”，填入自己的原始对话链接，例如：

```text
https://chatgpt.com/c/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

使用“恢复已有对话”关联到当前论文；也可使用“恢复当前聊天”记录当前页面。“返回绑定对话”用于回到已保存的聊天。

`/share/…` 是分享页面，不能作为自己的可继续聊天使用。绑定的对话必须能由当前登录账号访问。

“重新建立对话”会为当前论文开始新聊天。ChatGPT 网站上的旧对话仍然保留。如果正在排查自动绑定，先恢复已产生的对话，可避免重复创建。

## Prompt 和论文信息

自动初始化发送标题、作者、年份、期刊 / 会议、DOI、链接以及自定义 prompt，并附加联网检索和引用来源的要求。它不读取 PDF 正文，也不自动发送摘要、笔记或批注。

可以按研究目标调整 prompt，例如：

```text
请先根据标题和 DOI 检索这篇论文，再用中文解释：
1. 研究问题与已有方法的不足；
2. 方法的输入、输出、关键假设和主要步骤；
3. 实验基线、指标、结果及适用条件；
4. 与时间敏感网络调度研究的关系。
请引用来源，区分论文结论和你的推断。无法获取原文时明确说明。
```

要求联网不会保证网站一定启用搜索。必要时在 ChatGPT 网页中选择可用的搜索功能；拿不到全文时，基本信息不足以支撑完整论文分析。

工具菜单中的“复制论文信息”和“复制信息与批注”是独立的手动复制功能，可能包含摘要或文字批注，不属于自动初始化发送内容。

## 论文两侧留白

打开原 PDF 后点击顶部“两侧留白”，或使用“工具 → ChatGPT 论文助手 → 打开 / 创建两侧留白笔记副本”。插件在本地生成同一父论文下的加宽附件，默认左右各留 50 毫米。设置页可单独保存每侧宽度（10–150 毫米）。

新副本的空白区域是真实 PDF 页面的一部分，可用原生文本批注、画笔、橡皮擦和现有快捷键。原文件和批注不变；创建时已有批注会嵌入副本，可能显示为外部批注。原文与副本之后新增的批注各自保存，不自动合并。

相同原附件与宽度再次点击会打开已有副本。要使用新宽度，请回到原 PDF 修改设置后创建。已有副本不会被覆盖；删除副本会删除其中的笔记，请先确认需要保留的内容。加密或损坏的 PDF 可能无法生成，插件会提示错误并保留原文件。已签名 PDF 的副本经页面修改后不保留原数字签名的有效性。

## 方框与箭头批注

PDF 顶部批注工具栏中，画笔右侧有空心方框与箭头两个按钮。点击启用后，按住鼠标左键拖动绘制。**每画完一个形状会自动回到选择工具**，绘制下一个时重新点击相应按钮。箭头从鼠标按下的位置指向松开的位置。再次点击当前按钮、按 Esc 或切换其他批注工具即可退出。

选中已有方框，拖动蓝色角点可自由调整宽、高，不锁定比例。水平拖动只改宽度，竖直拖动只改高度；线条粗细保持不变。旧版本绘制的方框同样适用。

颜色由同一工具栏的颜色选择器设置；初始线宽沿用插件设置中的画笔粗细。方框与箭头以原生笔迹保存，可使用 Zotero 的撤销、重做、移动、删除和橡皮擦，也会随导出的 PDF 保留。单击不拖动不会产生批注；拖到页外的部分会限制在起始页面内。只读文档不能创建形状。

Ctrl 拖动页面和空格临时画笔 / 橡皮擦仍可使用。普通 PDF 与留白副本均支持，切换页面和重启后已保存的形状仍然保留。

## PDF 操作与批注

| 操作 | 说明 |
| --- | --- |
| Ctrl + 滚轮 | 放大 / 缩小 PDF |
| Ctrl + 左键拖动 | 平移放大的页面 |
| 按住 Ctrl + A，再点左键 | 新建文本批注并进入输入，松开后仍可继续打字 |
| 空格 + 左键拖动 | 画笔；松开并完成笔画后恢复原工具 |
| 空格 + 右键拖动 | 橡皮擦；仅擦除手写笔迹，期间不弹出右键菜单 |

文本批注创建后，点击别处或按 Esc 结束输入。输入框中的 Ctrl + A 仍用于全选，空格仍可正常输入。快捷键只处理 PDF 区域，并遵守只读限制。

默认样式的单位为 PDF 点（pt）。点击“保存批注样式”后，下次快捷键创建批注时生效；调整字号不会改变已有文本，调整颜色也不会修改已有笔迹。“恢复默认样式”可回到文字 14 pt 黑色、画笔 2 pt 红色、橡皮擦直径 16 pt。

## 登录

建议先在侧栏完成一次正常网页登录。插件会复用 Zotero 内的网页登录状态。可选自动登录仅尝试在 `https://auth.openai.com` 表单中填写保存的邮箱密码；登录流程中的验证码、双重验证和 Google / Microsoft / Apple 授权需要手动完成。

账号密码通过 Zotero 密码管理器保存，不放进普通插件偏好设置。点击“删除已保存的账号密码”删除这份凭据；网站会话如需退出，请同时使用 ChatGPT 自己的退出登录入口。

## 常见问题

### 提示插件不兼容，或重启后没有入口

确认版本为 Zotero 10.0.x，安装文件为本仓库提供的 `.xpi`。在“工具 → 插件”确认插件已启用，再重启 Zotero。目前没有声明支持 Zotero 7 / 8。请勿手动修改 Zotero 的插件注册文件或用户数据库。

### 侧栏没有自动发送

检查“首次展开论文聊天时，自动发送…”是否开启、当前是否已经登录以及网络是否正常。输入框已有自己的草稿时，插件不会覆盖；发送或清空草稿后重试。网站验证页需要先手动完成。发送结果无法确认时会暂停，避免重复提交。

### 已经产生回复，但切换后没有回到旧聊天

在“对话管理”中检查绑定状态，尝试“恢复当前聊天”，或填入该聊天的 `/c/…` 链接恢复。若再次出现，请记录 Zotero 版本、插件版本、切换步骤以及错误提示，并到 [Issues](https://github.com/HappyBoy-22/zotero-ChatGPT-/issues) 反馈。不要提交账号密码、Cookie、会话令牌或完整 Zotero 配置文件。

### 浏览器登录了，侧栏却要求重新登录

两者使用不同的会话存储，需要在侧栏内单独登录。网页登录后的功能和限额以这个账号为准。

### 论文没有全文，分析不够准确

插件只发送基本信息，不能保证 ChatGPT 获取到付费或不可公开访问的论文。检查引用来源；根据需要手动提供有权分享的片段或文件。

### 如何升级或卸载

升级时从文件安装新版 XPI，覆盖原插件并重启。卸载或禁用在 Zotero 插件管理器完成；已有原生 PDF 批注和 ChatGPT 网站上的对话不会被删除。插件本机偏好设置可能仍保留。

## 插入图片与缩放

点击箭头右侧的插入图片按钮，选择 PNG / JPG / WebP，再点击页面放置。普通页面与留白区域都可用。拖动图片移动，选中后拖动八个控制点调整宽高；按 Delete 或点击删除图片移除，Esc 取消放置。

图片复制到本机数据目录 `chatgpt-reader/images/`，按 PDF 附件单独保存，关闭和重启后恢复；不自动通过 Zotero 同步。分享或打印时使用 **工具 → ChatGPT 论文助手 → 导出含图片的 PDF**，普通 PDF 导出不包含插件图片层。原 PDF 不会被改写。
